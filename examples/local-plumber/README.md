# Example — a local plumbing company

> **Independent teaching example.** Example Plumbing didn't commission this and isn't a client. Everything comes from public pages captured October 12, 2026, so it will go out of date. Observations are sourced, inferences are labeled, and proposals are marked as proposals. The draft in `03-reviewer-run/` contains false statements on purpose.

All three rungs, run on one real business, on October 12, 2026, with every run cross-checked in a second AI.

This is **a worked example, not a template.** The generic prompts and templates are in the top-level folders; this folder shows what they produced on a real page, a real prospect, and a real draft. Nothing here needs editing to use the repo.

| Rung | What's here | What it shows |
|---|---|---|
| 1 | `01-schema-audit.md` | v1 of the schema audit prompt run on Example Plumbing's live homepage: eleven findings, corrected markup, and the ChatGPT cross-check that pushed the prompt to v2 |
| 2 | `02-prospect-folder/` | A six-file prospect folder built from public sources only, every line tagged. Three cross-check passes; its README says what each one changed |
| 3 | `03-reviewer-run/` | A first-30-days plan with six seeded mistakes; the reviewer and fact-checker run by hand in Claude and ChatGPT; then the current prompts run unattended on a schedule (`first-30-days-SCHEDULED-RUN.md`) |

**About Example Plumbing.** A real, family-run (per their site) plumbing company. The author has no connection to them. Chosen because they're a real business with a real site in an unrelated market. The name, owner and staff, towns, competitors, and contact details are replaced with placeholders. Every observation is sourced and dated; every inference is labeled. Raw captures (full page text, search results) aren't included — the files describe them. The site will have changed by the time you read this — that's expected, and the prompts don't care.
