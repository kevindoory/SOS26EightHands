# clients/

Your client folders go here, one per client, copied from `../_template/`.

No client data ships with the repo — this README is the only file here. The worked example is in `examples/`. Read it, don't edit it.

The repo's `.gitignore` already keeps everything else in this folder out of git. So if you fork the repo and keep it public, your client files won't get committed by accident. If you downloaded the ZIP and aren't using git, this doesn't matter — the files just live on your computer.

Client files are private. Keep them wherever you keep client documents now.
